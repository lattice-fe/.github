### Welcome to Lattice

Lattice is an open-source project building high-performance, developer-friendly local desktop tools. We believe file management should be fast, private, and inviting—not a sluggish utility you leave as quickly as possible.

### Core Philosophy

- **Local-First & Private:** All indexing, embeddings, and file edits stay strictly on your local machine. Zero telemetry, zero cloud requirements.
- **High Performance:** Sub-10ms full-text SQLite FTS5 indexing, 60fps selection boxes, and native Rust backend architecture.
- **Developer Ergonomics:** In-app syntax highlighting, live Markdown & HTML sandbox previews, Spotlight launcher (`Alt+Space`), and terminal CLI hand-offs.
- **Agent-Ready:** Designed from day one with structured JSON APIs, honest exit codes, and skill definitions for autonomous AI coding assistants.
